# 拼多多搬家助手（Chrome 扩展）

在拼多多商品页一键把商品推送到本地「煤炉多账号管理台」，由管理台自动翻译成日语、
按公式换算日元价格，再发布到 メルカリ / Yahoo!フリマ。

拼多多的风控不允许在指纹浏览器里访问，所以采集这一步放在日常使用的 Chrome 里，
通过本扩展把商品数据中转给本地管理台。

## 安装

1. Chrome 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库目录

## 使用

1. 确认本地管理台服务已启动（默认端口 8791）
2. 打开任意拼多多商品页（`mobile.yangkeduo.com` / `mobile.pinduoduo.com`）
3. 点击页面右下角红色的「搬到管理台」按钮
4. 到管理台的「搬家上架」页确认标题/价格/分类，选择发布目标后上架

## 配置

点击浏览器工具栏上的扩展图标可设置管理台服务器地址，并用「测试连接」验证是否连通。
留空时自动依次尝试：本机 → Tailscale → 局域网。

### 异地使用（浏览器和管理台不在同一个局域网）

两台设备装 [Tailscale](https://tailscale.com/) 登录同一账号，在跑管理台的机器上执行一次：

```
tailscale serve --bg --tcp 8791 tcp://127.0.0.1:8791
```

之后在任何一台 tailnet 内的设备上都能用 `http://<设备名>.<tailnet>.ts.net:8791` 访问，
把这个地址填进扩展弹窗保存即可（保存时 Chrome 会弹窗请求该地址的访问权限，必须允许）。

> 扩展只能请求 `host_permissions` / 已授权的地址。换了新的服务器地址一定要点「保存」走一次授权，
> 否则请求会被 Chrome 直接拦掉。

## 工作原理

| 文件 | 作用 |
|---|---|
| `content.js` | 在商品页注入悬浮按钮，监听 SPA 路由变化重新挂载 |
| `background.js` | 以 `world: "MAIN"` 注入脚本读取页面的 `window.rawData`，提取商品名、价格（单位为分）、图集，POST 给管理台 |
| `popup.html` / `popup.js` | 设置管理台服务器地址 |

商品数据来自拼多多页面自身渲染用的 `window.rawData`，不调用任何私有接口；
未登录拼多多时页面只有壳数据，扩展会提示「拼多多没登录」。

## 依赖

需要配套的本地管理台服务提供 `POST /api`（`action: "pdd_push"`）接口接收数据。
